# Фактическая недельная сборка от 02.10.2026

Именно эти скрипты собрали CSV на 66 труб: 22 091 841 строка, 50 колонок, 11 357 трубо-недель из 138 583 872 суточных строк. Последовательность: index_daily → prepare_plan → weekly_mean → verify_weekly → finish_reports. C использует macOS/CommonCrypto; бинарники не включены. Исходные пути, контрольные размеры и зависимость на суточные индексы сохранены. Средние только по имеющимся конечным значениям; ID не усредняются, полностью пустые параметры остаются пустыми.

## Каждый файл

- `FINAL_MANIFEST.json`: Оригинальный манифест: источники, SHA-256 и размеры текущих суточного и недельного CSV.
- `check_workbook.py`: Контроль Excel-отчёта недельной сборки.
- `finish_reports.py`: Финальные отчёты, манифест и оформление завершённого недельного результата.
- `index_daily.c`: Индекс суточного CSV: ID, дата, байтовые смещения и сегментные строки.
- `prepare_plan.py`: Календарный план недель понедельник–воскресенье из суточного индекса.
- `test_weekly.py`: Регрессионные тесты данного этапа.
- `verify_weekly.py`: Повторное чтение результата и сопоставление недельных средних с pandas.
- `weekly_mean.c`: Фактически использованный потоковый сборщик недельных средних по ID и сегменту.
