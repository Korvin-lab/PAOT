# Исходный большой Windows-прогон

Копии взяты из перенесённого с ПК результата от 21 сентября. Скрипты сохранены неизменёнными. Это архив скриптов: входы, DLL, старые результаты и полный каталог RUN сюда не копируются. Resume/complete жёстко привязаны к RUN_2026-09-19_17-30-11; запускать их в пустой папке нельзя.

## Каждый файл

- `RUN_MEGION_FULL_WINDOWS.bat`: Исторический Windows BAT этого этапа; требует исходные входы и структуру пакета.
- `add_h2s_gas_phase.py`: Добавление H2S газовой фазы в исходный 51-колоночный финал.
- `audit_final_quality_strict.py`: Проверка исходных данных и связей.
- `build_final_dataset_stage1_co2.py`: Исходная сборка stage1 из сегментного результата с химией и дополнительными входами.
- `build_megion_windows_inputs.py`: Первоначальная подготовка графа и суточных входов Мегиона.
- `clean_two_phase_chemistry_base.py`: Очистка двухфазной химической базы перед сборкой.
- `complete_megion_after_resume.py`: Завершение stage1 и финального CSV после resume последних двух труб.
- `create_ascii_aliases.py`: Создание ASCII-алиасов путей для совместимости исходного Windows-запуска.
- `fill_chem_full_coverage_variant3.py`: Историческое дозаполнение химии; в финальном актуальном CSV затем заменено этапом суточной медианы ниже.
- `fill_rules.py`: Общие правила интерполяции и заполнения рядов исходного пакета.
- `finalize_prepared_dataset.py`: Историческая финализация stage1 в суточный датасет.
- `main_pipeline_final_csv.py`: Исходный НЕисправленный полный PE2/PVT-расчёт из копии Windows-прогона 19–21 сентября; без правок гидравлики 5 октября.
- `make_training_dataset_no_gaps_variant3.py`: Исторический вариант подготовки обучающей таблицы без пропусков.
- `post_run_validate_new_dataset.py`: Контроль результата после сборки.
- `preflight_84.py`: Унаследованная предварительная проверка исходного пакета.
- `preflight_megion.py`: Предварительная проверка входов Мегиона.
- `prepare_auxiliary_series.py`: Подготовка исходных вспомогательных рядов.
- `preprocess_requested_fill_active.py`: Подготовка и дозаполнение режимов в рабочем календаре.
- `rebuild_chemistry_inputs.py`: Первоначальная подготовка химических рядов для пакета.
- `recover_full84_inputs.py`: Вспомогательный унаследованный этап восстановления входов; название 84 не является числом труб итогового Мегиона.
- `requirements_windows_py311.txt`: Версии библиотек исходного Windows-пакета.
- `resume_megion_strict_last_pipes.py`: Фактическое продолжение незавершённого прогона для последних двух труб 1751068454 и 1751067083.
- `rough_temperature_model.py`: Температурная модель исходного большого прогона.
- `run_config.json`: Историческая конфигурация исходного запуска.
- `run_full.py`: Общий сценарий Windows-сборки, включённый в исходный пакет.
- `run_megion_full.py`: Сценарий полного первоначального запуска Мегиона.
- `summarize_zero_days.py`: Сводка значений и покрытия данного этапа.
- `test_add_h2s_gas_phase.py`: Регрессионные тесты данного этапа.
- `test_new_pressure_logic.py`: Регрессионные тесты данного этапа.
- `test_preparation_rules.py`: Регрессионные тесты данного этапа.
- `validate_temperature_segments.py`: Независимая проверка результата данного этапа.
- `ПРОЧИТАТЬ_ПЕРЕД_ЗАПУСКОМ.md`: Оригинальная инструкция исходного пакета; не инструкция автономного запуска этой коллекции.
